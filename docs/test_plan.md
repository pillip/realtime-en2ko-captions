## Strategy

- **Testing pyramid (current)**: ~75% unit (string-matching or pure-function), ~0% integration, ~15% e2e (excluded from default run). This is effectively an inverted pyramid — the most expensive and fragile layer (fullscreen HTML string matching) accounts for a significant fraction of test count.
- **Testing pyramid (recommended)**: 70% unit (pure logic), 20% integration (WebSocket protocol, DB + handler combined), 10% e2e (login flow + caption pipeline smoke)
- **Priority**: Risk-matrix-driven. P0 gaps have High complexity + zero coverage and are on the critical user path. P1 gaps have High complexity + partial coverage or Medium complexity + zero coverage.
- **CI integration (current)**: None.
- **CI integration (recommended)**: Add a GitHub Actions workflow with two stages — (1) `pytest -m 'not e2e'` on every push/PR with `--cov` threshold ≥ 60%; (2) e2e stage on merge to `main` only, requiring a running Streamlit server in CI (Docker Compose step).

## Edge Cases & Boundary Tests (Missing)

The following edge cases were identified through code inspection with no corresponding test:

1. **`_record_usage` with `audio_duration = -1`** (negative): The guard is `if audio_duration <= 0`, so negatives are treated as zero and estimated. No test confirms this. `[INFERRED]` — `websocket_handler.py:171`

2. **`detect_language` with empty string**: `any(... for c in "")` returns False, so empty string is classified as `("en", "ko")`. This is consistent but untested.

3. **`split_into_sentences` with very long single sentence (no delimiters)**: Returns a list with one element equal to the original string. Untested.

4. **`check_usage_limit` for admin with `usage_limit_seconds=0`**: The admin short-circuit fires before `get_remaining_seconds` is called, so `remaining_seconds` of 0 is never evaluated for an admin. The ordering is critical; a regression that moves the role check below the remaining check would silently block admins. No test guards this ordering. `[INFERRED]` — `auth.py:163-171`

5. **`User.get_remaining_seconds` for user with `usage_limit_seconds=0` (non-admin)**: Returns 0, which means `check_usage_limit` will deny any non-zero duration request. Untested. `[INFERRED]` — `database.py`

6. **`create_openai_session` ephemeral token expiry**: The `expires_at` is hardcoded to `datetime.now() + timedelta(minutes=1)` regardless of what the OpenAI API returns. This means expired tokens may be incorrectly accepted on the server side. No test covers token expiry logic. `[INFERRED]` — `services.py:74`

7. **`_authenticate_client` with malformed JSON**: `json.loads` raises `json.JSONDecodeError`; this is caught by the outer `except Exception` and returns None. No test confirms the handler does not crash.

8. **Concurrent `add_usage` calls**: SQLite without WAL mode and without `PRAGMA foreign_keys = ON` may behave unexpectedly under concurrent writes. `database.py` uses context managers per call, but multiple Streamlit sessions translating simultaneously could cause lock contention. No concurrency test exists.

9. **`generate_session_token` collision**: Tokens derived from `SHA-256(user_id:username:epoch_seconds)` will be identical if two login events occur within the same second for the same user. No test asserts uniqueness within the same second.

10. **`webrtc.html` caption DOM cap at 100**: After 100 elements are added, `captionContainer.firstChild` is removed. No E2E test injects 101 captions and confirms the oldest is removed.
